# MitchellCo Maps

Interactive public-data maps built as standalone HTML pages.

This repository consolidates the MitchellCo map collection, including wildfire, weather, drought, earthquake, infrastructure, environmental, and space-weather maps.

## Maps

The map HTML files live at the repository root so they can be published directly with GitHub Pages.

## Data and dependencies

Individual maps document their own public data sources and refresh behavior. The project avoids API keys and account-based dependencies where practical.
