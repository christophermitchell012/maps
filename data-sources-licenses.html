Data sources and licenses

MitchellCo uses this page to provide more source, license, provenance and attribution information than can reasonably fit inside a map control. This is an operational publication record, not legal advice. Source terms can change, so links below point to the source organizations' current guidance.

Publication policy

MitchellCo public maps fail closed on source permissions: sources classified as blocked, needing clearance, unknown, or unreviewed are not intentionally published. Derived scores and interpretations are MitchellCo products, not products or endorsements of the underlying data providers. MitchellCo does not use NASA, NOAA/NWS, or other government logos as site branding.

Map 26 · Dark Sky Tonight

NASA VIIRS Black Marble annual imagery, 2016

Rendered reference imagery

Visible map credit: NASA Worldview / GIBS · Suomi NPP/VIIRS via NASA Earth Observatory · Black Marble 2016.

The map's historical nighttime-light overlay is delivered through NASA's Global Imagery Browse Services (GIBS). NASA Worldview identifies the layer as Black Marble - Nighttime Lights only (Annual, 2012 & 2016) from Suomi NPP/VIIRS via NASA Earth Observatory. MitchellCo uses the 2016 layer as historical visual context, not as a current sky-brightness measurement.

NASA VIIRS VNP46A4 Collection 2, 2024

Scientific radiance data

The ranking prototype uses the 2024 annual VNP46A4 Collection 2 product at build time. The Earthdata token used to access LAADS is a private build credential and is not included in public HTML, JavaScript or JSON.

Dataset citation supplied for the product:
NASA VIIRS Land Science Investigator-led Processing System. (2025). VIIRS/NPP Lunar BRDF-Adjusted Nighttime Lights Yearly L3 Global 15 arc second Linear Lat Lon Grid [Dataset]. NASA Level 1 and Atmosphere Archive and Distribution System Distributed Active Archive Center. doi:10.5067/VIIRS/VNP46A4.002.

MitchellCo reports the source radiance in nW/(cm²·sr). It is an upward-emitted/nighttime radiance measure, not a Bortle class and not a direct measurement of zenith sky brightness.

NOAA / National Weather Service API

Forecast data

Cloud-cover values come from the NOAA/NWS API and retain their forecast time. NWS states that its web information is public domain unless specifically noted otherwise and requires users not to imply government endorsement or present modified content as official government material.

  • NWS API documentation
  • NWS disclaimer and reuse conditions

MitchellCo's viewing score is derived from source data and is not an official NOAA/NWS forecast. Internet delivery is not guaranteed.

Release philosophy

When a source requires a specific notice, year, copyright statement, citation, or license link, MitchellCo retains it. If the required year is not known from the source data, publication is held rather than guessed. Sources with unresolved commercial-use or redistribution terms are excluded until cleared.
